# Cross-tool research brief

**Run in:** claude.ai with Readwise, Recall, and Notion connectors enabled
(or Claude Code — it reaches the same connectors). Use when starting a post,
playbook chapter, or client question: *"what do I already know about X?"*

---

Research question: **<X>**

Search my knowledge in this order and label which tool each finding came from:
1. **My vault** (repo `gyates45/curated`, `second-brain/notes/`) — what I've
   already concluded. These are my positions; treat them as the spine.
2. **Readwise highlights** — what I've read and marked on this. Include the
   source title per highlight.
3. **Recall cards** — summaries and connected concepts I may have forgotten.
4. **Notion** — any operational context (past projects, drafts, trackers).

Then produce a brief:
- **What I already believe** (from the vault, with note paths)
- **Evidence I've collected** (highlights/cards, deduplicated, ≤10 items)
- **Gaps & contradictions** — where my sources disagree or I have no coverage
- **Recommendation:** enough to write from now, or does this need a
  NotebookLM deep-dive / ChatGPT deep-research run first?

End with a draft `inbox/` note capturing the brief so the weekly review can
distill it.
