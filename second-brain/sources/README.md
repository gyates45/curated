# sources/ — literature notes

One note per consumed source (article, book, video, podcast): its highlights
plus your reactions. This is the middle layer between raw capture and evergreen
notes.

- **`readwise/`** — machine-synced by `scripts/readwise_sync.py`. Gitignored
  (public repo; bulk highlights are copyrighted text). Never hand-edit; it gets
  regenerated. Commentary belongs in `notes/`.
- **Hand-made source notes** (this folder, committed) — for sources worth a
  proper write-up in your own words: use `templates/source-note.md`, keep
  quotes short and attributed.
