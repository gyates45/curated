# projects/ — active initiatives

One folder per active project (a playbook kit, a workshop, a content series, a
site rebuild). Each gets a `project.md` from
[`templates/project.md`](../templates/project.md) stating the goal, deadline,
and next action — plus whatever working files it needs.

- Project **status** (calendar, pipeline, tasks) lives in Notion; project
  **thinking** lives here.
- Client-identifiable material goes in a `private/` subfolder — gitignored,
  because this repo is public.
- Stalled for a month with no next action → `archive/` (the weekly review
  asks).
